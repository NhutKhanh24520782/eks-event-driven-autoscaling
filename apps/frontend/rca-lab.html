🚀 Reproducible Experiment Workflows (k6 & Chaos)

Execute these scripts from the repository root. Commands are automatically generated with your active endpoints. Always adhere to the approved execution sequence: Baseline → Load Scale-out → Pod Failure.

Platform:
01 · Baseline

Low Steady Load

1 VU for 30s. Records baseline API enqueue acknowledgement and worker processing without queue backlog.

02 · Autoscaling

Scale-Out Load Test

Ramps to 10 VUs, holds 60s, ramps down. Breaches SQS `queueLength=5` threshold and verifies scale-out to 4+ replicas.

03 · Traffic Burst

Sudden Spike Test

Instant jump to 20 VUs in 5s. Tests rapid backlog accumulation, scale-out responsiveness, and recovery timing.

04 · Chaos Resilience

Worker Pod Failure

Guarded failure test: terminates active worker pod mid-job, validating SQS visibility timeout and zero message loss.

Node / AZ failure tests are strictly gated: requires team approval, isolated environment, and rollback plan.
